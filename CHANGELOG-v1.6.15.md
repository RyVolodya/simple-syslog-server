# Simple Syslog Server v1.6.15

## Dashboard donut polish

- Informational severity is always green in Event severity.
- Warning severity is always red in Event severity.
- Event health uses semantic colors: Critical/Error purple, Warning red, Normal green.
- Traffic concentration values are rounded to two decimal places.
- Traffic concentration center value now includes the percent sign.
- Traffic concentration tooltip now shows locale-formatted percentages such as `25,96%`.
