# Simple Syslog Server v1.6.9

## Mobile messages and smooth live updates

- Mobile Messages rows now render as responsive cards.
- Full message text is shown on mobile and wraps across multiple lines.
- Background polling no longer replaces the table with a Loading state.
- Existing table data remains visible until fresh data arrives.
- Recharts line updates no longer replay the line animation.
- ApexCharts donut updates no longer replay chart animations.
- All v1.6.8 Print/Excel functionality is preserved.
