# Simple Syslog Server v1.6.8

## Messages print workflow

- Renamed the `PDF` action to `Print`.
- `Print` opens a dedicated printable Syslog Messages table.
- The print view respects the active Messages filters.
- The browser's native print dialog is used, so users can choose a physical printer or `Save as PDF`.
- Table headers repeat on multi-page printouts.
- Column widths are optimized for A4 landscape printing.
