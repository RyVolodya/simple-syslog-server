# Simple Syslog Server v1.6.21

## Fixes

- Fixed Settings `Edit` / `Save` vertical alignment with input and select controls.
- Preserved zero top-margin for stacked mobile Settings controls.
- Fixed `Traffic concentration` occasionally showing `Top 10 100.01%`.
- Device traffic percentages are now calculated from raw message counts and the exact 24-hour total instead of summing rounded percentages.
- `Other devices` is calculated as the exact remainder from 100%.
